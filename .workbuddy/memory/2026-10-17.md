- **[低] 真缺陷②：锁徽标（未解锁卡右上角）根本没有锁梁**——`arc(cx, bodyTop, s*0.7, π, 2π, false)` 圆心取在锁体**下**边缘，加上 `false` 的补集语义 → 上半圆正好埋进填充的锁体里 → 形态退化成**纯圆角方块**（M2-7 起就如此，前两轮审查都没抓到）。修法（已验证）：圆心移到锁体**上边缘**（`bodyTop + s*1.6`）+ `arc(…, 0, π, true)` → 渲染出标准挂锁「∩ + 体」
- **根因（已记 MEMORY.md 引擎限制）**：Cocos 3.8.8 `Graphics.arc` 的 `counterclockwise=false` = **从 start 顺时针（角度递减）扫到 end**，扫出的是 `[start,end]` 的**补集**；要画标称区间必须传 `true`。**M2-10 通关庆祝的星光/动效若用弧，先按这条写。**

- **通过项**：`sfx.ts` 纯数据（durationMs 由 pulses 推导，不手写）；`AudioAdapter` 三处 WebAudio 细节都对（suspended 先 resume、同 key 重触发先 stop 防叠音、包络起振 8ms + 释音**恒收敛到 stop 时刻**防切击）；无 WebAudio 优雅降级 `unavailable`（微信端不抛错）；`setMuted` 走读改存、`muted` 缺省回退 false（旧档兼容 `typeof v.muted==='boolean'`）；`select` 只认 select 意图（grab/deselect/rotate 都不响）；`onDestroy stopAll` 防通关钟拖进下一场景；R-A4 无 wx API（注释里的 `wx.` 文案没被守卫误伤）
