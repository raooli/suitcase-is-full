## 复审：M2-9（7d88d4e）—— 结论 PASS，2 条 [低]（同一根因：Graphics.arc 语义）+ 1 条 [低] 类型洁癖

- **独立复验（不轻信提交信息，全部无头 E2E）**：`npm run check` **321/321**。首页开关 (195,722)：`静音：开` → `已静音，跳过 select` → `音效开关：开 → 关（已保存）`；`--reload` → `首页：… / 音效关`（**AC18** ✓）。L1：place-ok×4（四拖通关）→ success（2 脉冲/340ms）；`--tap 62,658` 选中 → `播放音效 select`；A@(0,0) 后原地再放 → `placement-rejected` → place-fail。静音路径：`已静音，跳过 place-ok`。全程零 Console 错误
- **[低] 真缺陷①：喇叭「有声」态的两道声波弧画反了方向**。`arc(3,0,r,-π/3,π/3,false)` 实际渲染的是**补集**（240°）：像素级角度直方图 **0/232 个弧像素落在预期 ±60° 内**，角度范围 −155°~+162° → 弧绕到喇叭**背后**一大圈（截图放大可见像套了个圆环）。修法（已验证）：末参传 `true` → 165/183 像素落在 ±60°（余 18 个越界像素全落在 y=4 的喇叭锥边界的多边形舍入上，非弧体）
- **[低] 真缺陷②：锁徽标（未解锁卡右上角）根本没有锁梁**——`arc(cx, bodyTop, s*0.7, π, 2π, false)` 圆心取在锁体**下**边缘，加上 `false` 的补集语义 → 上半圆正好埋进填充的锁体里 → 形态退化成**纯圆角方块**（M2-7 起就如此，前两轮审查都没抓到）。修法（已验证）：圆心移到锁体**上边缘**（`bodyTop + s*1.6`）+ `arc(…, 0, π, true)` → 渲染出标准挂锁「∩ + 体」
- **根因（已记 MEMORY.md 引擎限制）**：Cocos 3.8.8 `Graphics.arc` 的 `counterclockwise=false` = **从 start 顺时针（角度递减）扫到 end**，扫出的是 `[start,end]` 的**补集**；要画标称区间必须传 `true`。**M2-10 通关庆祝的星光/动效若用弧，先按这条写。**
- **[低] 类型洁癖**：`core/model/types.ts` 的 `SfxPulse.waveform: OscillatorType` 是 **lib.dom 的浏览器类型**，core 本应平台无关（R-A1 只管 `cc`）。建议换成自家联合类型 `'sine'|'square'|'triangle'|'sawtooth'`（M4-4 换 wx 音频后端时也更贴切）。类型层耦合、非运行时问题
- **通过项**：`sfx.ts` 纯数据（durationMs 由 pulses 推导，不手写）；`AudioAdapter` 三处 WebAudio 细节都对（suspended 先 resume、同 key 重触发先 stop 防叠音、包络起振 8ms + 释音**恒收敛到 stop 时刻**防切击）；无 WebAudio 优雅降级 `unavailable`（微信端不抛错）；`setMuted` 走读改存、`muted` 缺省回退 false（旧档兼容 `typeof v.muted==='boolean'`）；`select` 只认 select 意图（grab/deselect/rotate 都不响）；`onDestroy stopAll` 防通关钟拖进下一场景；R-A4 无 wx API（注释里的 `wx.` 文案没被守卫误伤）
