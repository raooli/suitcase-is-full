# v0.1.0 · 10 关 MVP 与下一阶段规划

发布日期：2026-11-12

首个 GitHub 源码版本，记录《行李箱装不下啦！》现有 10 关收纳解谜 MVP，并收录本轮产品与架构审查及第 11–20 关设计。项目版本与 package.json 保持为 0.1.0。

## 当前可玩内容

- 10 个配置化关卡，支持拖拽、网格吸附、合法性预览、90°旋转、取出、撤回与重置。
- 首页选关、关卡解锁、本地进度存档、首次操作引导、通关反馈与音效开关。
- Cocos Creator 3.8.8、TypeScript；纯逻辑 core 与 Cocos view 分层，GameSession 统一处理状态变更。
- 63 张物品图、3 张 UI 插画及 4 个音效资源已接入。
- 微信小游戏构建与音频后端、短屏布局阶梯已具备；微信真机性能与音频仍需完成专项验证。

## 验证

- npm run check：core/view 类型检查、架构守卫、10 关数据及可解性校验、20 个测试文件共 354 条测试通过。
- 本轮审查复用现有 Web 构建，在 390×844 与 320×568 视口预览无 Console 错误；没有重新生成并认证游戏发行二进制。
- 本次新增内容为文档与版本记录，玩法实现沿用当前 MVP。

## 已知问题与版本边界

- 当前提示只保证局部合法，可能导致剩余布局没有续解；第 8、10 关已有复现，后续优先修复。
- 底部托盘格形可读性优化及第 11–20 关仍是规划，尚未实现。
- 短屏首页标题裁切、扩关后的选关容量与旧版全通存档迁移需要后续处理。
- 微信真机音频、帧率和前后台恢复仍待专项验证。本次 GitHub Release 为源码归档，未提交微信审核，也未附加新的游戏安装或部署包。

## 本地运行

1. 使用 Cocos Creator 3.8.8 打开项目，生成本地引擎声明和配置。
2. 安装依赖：npm ci。
3. 执行检查：npm run check。
4. 运行预览：npm run preview:game；预览脚本要求 Node.js 22 或更新版本。

GitHub 自动提供与 v0.1.0 标签对应的源码 ZIP / tar.gz。
